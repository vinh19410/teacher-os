The admin problem

Teaching is the easy part. The admin isn't.

Most tutors already know how to teach IELTS. The leak is everything around the lesson.

Schedules scattered across tools

Class times live in a calendar, a notebook, and three chat groups. A cancelled Thursday still shows up as a billed hour.

Grading and invoicing by hand

Task 2 scripts sit in Drive. Bank details sit in a sheet. You rebuild the same invoice every time a package ends.

Students chasing updates

Parents message at 21:40 for a score you already wrote down. The record is somewhere — just not where they can see it.

FAQ

Questions before you join.

Who is it for?

Independent teachers and tutors — especially IELTS and English test prep — and small centres with about 2–10 teachers. If you currently run classes in a spreadsheet plus a chat group, you are the intended user.

Do students need accounts?

No. You can run the whole class yourself and share lesson or report links when you want. Optional student access is invite-only, for submitting work and reading feedback.

What happens to my data?

Class lists, submissions, and invoices stay in your workspace. We do not sell teacher or student data. You can export records and leave; nothing is held hostage in a proprietary format we refuse to download.

Which browsers?

The latest two versions of Chrome, Safari, Edge, and Firefox on desktop, plus the same engines on a phone. Teacher OS is a responsive web app — no install, no store listing.

When do you launch?

The waitlist is open now. We onboard in waves so each workspace can be set up with real classes, not a generic demo. You’ll get an email when your invite is ready.
